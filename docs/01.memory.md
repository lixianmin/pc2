# Memory

## 命名规范

文件名统一用 kebab-case：`memory-search.ts`、`turn-end-callback.ts`、`memory-and-context.md`。

| 范围 | 规则 | 示例 |
|------|------|------|
| 文件名（.ts, .md, .json 等） | kebab-case | `memory-search.ts`, `agent-loop.ts` |
| 变量、函数、类型、接口 | camelCase | `turnEndCallback`, `memorySearch` |
| 常量、环境变量 | UPPER_SNAKE_CASE | `MAX_ROUNDS`, `FREEZE_THRESHOLD` |
| JSON 字段名 | camelCase（跟随 TS） | `{ "lastRun": null }` |

## 关键决策

- **BAML 函数参数之间必须用逗号分隔**：`function Foo(a: string, b: string)` 不加逗号会导致 "This line is invalid" 编译错误
- **BAML 不支持在同一文件中将引用数组类型的 class 与 function 混用**：如果一个 class 有 `field OtherClass[]`，则同文件中不能定义 function。解决方案：class 和 function 分文件
- **BAML client 名称必须大写开头**：`Glm5Turbo` 而非 `glm_5_turbo`
- **BAML generator output_dir** 设为 `..` (项目根目录)，BAML 会自动在 output_dir 下创建 `baml_client/` 子目录
- **BAML ToolCall.arguments 是 string**（LLM 原始输出），应用层 ToolCall.arguments 是 `Record<string, unknown>`（解析后）。两套类型不混用
- **cron-parser v5 API**: 使用 `CronExpressionParser.parse()` 而非 `parseExpression()`（已弃用）
- **tsconfig rootDir 设为 `.`**: 因为 baml_client/ 在 src/ 外面，需要 `"rootDir": "."` 并 include `["src/**/*", "baml_client/**/*"]`
- **BAML class+function 分文件**: class 定义在 types.baml / memory-types.baml / verify-types.baml，function 定义在单独的 .baml 文件中
