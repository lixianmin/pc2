# PDF Processing Skill

## 前置检查

1. 运行 `which mineru` 检查 MinerU 是否已安装
2. 如果未安装，告诉用户安装方法（见下方"安装指南"），停止
3. 如果用户未提供文件路径，用 ask_user 询问 PDF 路径

## 处理单个 PDF

给定 PDF 路径 `<input>`（`stem` = 去掉扩展名的文件名）:

1. 创建输出目录: `mkdir -p /tmp/pc2-pdf/{stem}`
2. 执行转换:
   ```
   mineru -p <input> -o /tmp/pc2-pdf/{stem}
   ```
   - 如果 mineru 失败，尝试 fallback:
     ```
     marker_single <input> /tmp/pc2-pdf/{stem}
     ```
3. 找到输出 Markdown 文件（搜索 /tmp/pc2-pdf/{stem} 下的 .md 文件）
4. 用 file_read 读取 Markdown 内容
5. 向用户呈现内容 / 回答问题

## 入库到 LMD（可选）

用户要求"入库"或"记住"时：
1. 提取关键信息（事实、结论、关系）
2. 用 memory_search 检查是否已有相似内容
3. 用 addMemory 写入 LMD（type: fact 或 episode）

## 错误处理

| 错误 | 处理 |
|------|------|
| mineru 未安装 | 输出安装指南，停止 |
| 转换失败（mineru） | 尝试 marker_single fallback |
| marker_single 也失败 | 报错，建议用户检查文件是否加密/损坏 |
| 找不到输出 .md | 检查其他子目录，报告实际输出结构 |
| 未提供文件路径 | 用 ask_user 询问 |

- [ ] **Step 1: Write test for skill command matching logic**

Create `tests/unit/cli/chat-skill-command.test.ts`:

```typescript
import { describe, it, expect } from 'vitest';

describe('skill slash command matching', () => {
  const skills = [
    { name: 'pdf-process', description: 'PDF', evolvable: true, filePath: '/fake' },
    { name: 'other-skill', description: 'Other', evolvable: true, filePath: '/fake2' },
  ];

  function matchSkill(input: string) {
    return skills.find(s => input.startsWith('/' + s.name + ' ') || input === '/' + s.name);
  }

  it('matches skill with args', () => {
    const matched = matchSkill('/pdf-process path/to/paper.pdf');
    expect(matched?.name).toBe('pdf-process');
  });

  it('matches skill without args', () => {
    const matched = matchSkill('/pdf-process');
    expect(matched?.name).toBe('pdf-process');
  });

  it('does not match partial name', () => {
    const matched = matchSkill('/pdf-pro path/to/paper.pdf');
    expect(matched).toBeUndefined();
  });

  it('does not match unrelated input', () => {
    const matched = matchSkill('please help with pdf');
    expect(matched).toBeUndefined();
  });

  it('extracts args correctly', () => {
    const input = '/pdf-process path/to/paper.pdf';
    const skill = matchSkill(input)!;
    const args = input.slice(('/' + skill.name).length).trim();
    expect(args).toBe('path/to/paper.pdf');
  });

  it('returns empty string for no args', () => {
    const input = '/pdf-process';
    const skill = matchSkill(input)!;
    const args = input.slice(('/' + skill.name).length).trim();
    expect(args).toBe('');
  });
});
```

- [ ] **Step 5: Add skill slash command dispatch in chat.ts**

In `src/cli/chat.ts`, after the `/resume` handler (line 146) and before `ensureThread` (line 148), add:

```typescript
const matchedSkill = skills.find(s => input.startsWith('/' + s.name + ' ') || input === '/' + s.name);
if (matchedSkill) {
  const args = input.slice(('/' + matchedSkill.name).length).trim();
  const skillBody = matchedSkill.body ?? '';
  const agentInput = `${skillBody}\n\n---\n\n用户要求: ${args || '请帮我处理文件'}`;
  const threadDir = ensureThread(agentInput);
  let textYielded = false;
  for await (const event of loop.execute(agentInput, { threadDir, dataDir: config.dataDir, lmdClient, sops, skills })) {
        if (event.type === 'text') {
          textYielded = true;
          process.stdout.write(event.content);
        } else if (event.type === 'tool_result') {
          process.stdout.write(`\n[tool: ${event.name}] ${String(event.result).slice(0, 200)}\n`); // 200 chars: enough to see result summary
        } else if (event.type === 'warning') {
          process.stdout.write(`\n[warning] ${event.content}\n`);
        } else if (event.type === 'done') {
          if (!textYielded) {
            logo.warn('Chat loop completed without text output', { reason: event.reason });
          }
          process.stdout.write('\n');
        }
  }
  const meta = await readMeta(threadDir);
  await updateMeta(threadDir, {
    lastActivityAt: formatTimestamp(),
    messageCount: (meta?.messageCount ?? 0) + 1,
  });
  continue;
}
```

This keeps the exact same event rendering pattern as the main loop (lines 150-165), preserving the magic number comment and the `logo.warn` call.
